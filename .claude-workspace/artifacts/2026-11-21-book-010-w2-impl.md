## Key Decisions
- **Diner room = largest fitting party per slot, computed server-side with W1's `fitsFor`** (binary search 0..maxParty), sent only where below the max party. The page compares `party <= room`; it never counts, so it cannot disagree with the server rule. Sending room instead of raw counts/stops also keeps guest counts and staff names off the public page.
- **"Schedule in use"** = hours stored, or the table edited away from empty (the same test that already decides whether hours are sent). BOOK-009's `scheduleEnabled` switch is not on this branch; at I-010 `scheduleInUse` is the one place to add it.
- **No party chosen** reads as a party of 1 (stopped / no-seat slots show 已滿 before a party is picked).
- **Party change** clears a chosen day that becomes 已滿, else a chosen time that no longer fits.
- **A min-notice "no time left today" day** keeps BOOK-009's `data-state="full"` without the 已滿 label; the new `booked` state also renders `data-state="full"` (spec id) and shows 已滿. A test can tell them apart by the label.
- **Over-limit prompt is inline** (S1 mockup: bottom of the day panel), not a modal; in Table view it renders above the table. Focus goes to Confirm anyway.
- **Pending note** only after stopping a period (brief); counts pending rows of that date in the period's range from the loaded month.
- **Stopped-by** shows W1's `stoppedBy` (email local part, W1 decision) and HH:MM in Hong Kong time; with no name, "Stopped · HH:MM".
- **Month badge** wraps under the guest count when the cell is narrow (walk found the count truncated; fixed, re-audited).
- Staff copy follows the app locale (en / zh-HK); diner copy in both message files.
