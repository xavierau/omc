## Key Decisions

- **Resolve rule (malformed → null):** not an object, no `weekly` object, or any weekly/special period that is not an HH:MM pair → the whole value is null (times unknowable, so today's behaviour). Scalars out of their option list fall back to defaults; a malformed special date is dropped; text fields fall back to ''. Missing weekday = closed.
- **Error keys follow the brief literally:** `closed_day` on `date`; `outside_hours`, `too_soon`, `too_far` on `time`; `terms_required` / `invalid` on `acceptTerms`. Existing `past` (date) and `past_time` (time) still win, so AC-5 is exact.
- **Notice:** a slot must be later than now AND at least `noticeHours` ahead, measured across midnight; exactly on the boundary is accepted.
- **Overlap:** two periods sharing any booking time (12:00–14:00 and 14:00–15:00) overlap, since 14:00 would be offered twice.
- **Terms snapshot:** both set languages joined by a blank line, zh-HK first (the booking page is bilingual). W3 should render the same text it stores, or say so if it shows one language only.
- **Past special dates:** the PUT rejects them (AC-2); GET drops them so a re-save of a loaded form never fails on a date that went past (spec S1.4). Resolve keeps them (no clock there); `slotsFor` ignores past dates anyway.
- **`summarize` lists every stored special date** (no clock); callers that need "in the window" (W4, AC-15) filter first.
- **`acceptTerms` is now an allowed page field** even without terms (ignored then); before it was `unknown_field`.
- **PAP path** now enforces hours and terms through `bookingRulesAt(now, config)`. `accept_terms` is not yet an agent API field (W4), so a PAP booking at a restaurant WITH terms set is refused `acceptTerms: terms_required` until W4 lands. No tenant has terms today.
- **AI tools not switched:** `src/application/agent/{agent-booking-tools,agent-booking-change-tools}.ts` still call `bookingRulesAt(now, config.maxPartySize)` (3 call sites, outside files_allowed). The number overload keeps the BOOK-001 rules for them. Switching them is a one-token change each (`config.maxPartySize` → `config`) but also needs the AI terms acceptance (AC-17), which is W4. See handoff blocker.
