## Key Decisions

- **Slots on the client from the shared pure helper** (decide_yourself): the view model sends `hours` + the HK clock; `slotsFor` / `periodsOn` / `windowEnd` from `src/domain/services/booking-hours.ts` compute days and slots in the browser, so the page and `checkSlot` cannot disagree at the same clock. A 90-day precomputed map would have been ~4k objects per page load. A test asserts every offered slot passes `checkSlot`.
- **Times changed (AC-9)** = a 400 whose `date` or `time` code is `closed_day|outside_hours|too_soon|too_far|past|past_time`: clear the time only, show `booking-times-changed`, `router.refresh()` (the force-dynamic page recomputes the view; client state survives). `past`/`past_time` included because a page left open past its slot is the same situation. No new API route needed (none in files_allowed).
- **Hours opt-in (AC-5)**: Simple mode sends `bookingHours` only when stored hours exist or the edited table differs from `EMPTY_BOOKING_HOURS`; otherwise the key is omitted (server keeps null). Off/External never send it. The resolver adds `schedule` only when hours are set, so the null view is byte-identical to BOOK-001 (existing resolver/page/form tests unchanged and green).
- **All-closed hours**: settings warn (`booking-settings-hours-warning`); the diner link shows the existing off page (no bookable time anywhere in the window).
- **Terms on the page show both set languages, zh-HK first** — the same text W1 stores as the accepted snapshot. Mockup D1 showed Chinese only; this deviates on purpose so "the exact text accepted" is what the diner saw.
- **Relabel by value, not key**: `bookingSettings.bookingRules` now reads "其他訂座資料（只供 AI 助手）/ Other booking notes (AI assistant only)" in every mode that shows it (Simple and External), keeping the existing test's key. In External mode the label says "other" with no structured hours above it.
- **Time pickers are 24-hour `<select>`s on the 15-minute grid ≤ 23:45** (not `<input type=time>`): Chrome in a 12-hour locale rendered 14:00 as a clipped "02:00". A stored value off the grid is kept as an extra option.
- **Party chips 1..max** literally (max may be up to 100 → a long grid); not capped.
- **Summary language** follows a message key (`bookingSettings.bookingHours.summaryLanguage`), since the tests' next-intl mock has no `useLocale`.
- **Design gate**: flattened the bordered info / calendar / terms / special-date / hours-table boxes into border-y bands (detector `nested-cards`); the mockups' boxed look is softened. Colours use existing tokens only (`primary`, `muted`, `pending-soft`/`pending-foreground` for warnings, `destructive`).
- `.next` artefact: `next dev` re-adds an agent block to `CLAUDE.md`; reverted (outside scope), not committed.
