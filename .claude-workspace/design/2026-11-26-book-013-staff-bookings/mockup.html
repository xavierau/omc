BOOK-013 · Staff create, edit and cancel bookings

Mockup on the BOOK-004 Bookings page. Spec: specs/2026-11-26-book-013-staff-booking-crud. Owner rules: staff bookings start confirmed; WhatsApp notify checkbox on by default; rule breaks warn and can be overridden; cancel is soft; edit/cancel apply to every pending/confirmed booking.

What changes on the page

  1. New booking button in the page header (primary), and + Add in the day panel header (date pre-filled).
  2. Every pending/confirmed row gets a ⋯ menu: Edit booking, Cancel booking (confirmed only; pending keeps Decline).
  3. Staff-made rows carry a By staff · Mandy source badge; cancelled rows are grey and struck through (BOOK-005).
  4. The time picker shows each slot's room (guests left). A full or stopped slot stays selectable; saving shows the rules prompt.
  5. Today view (new, default on phone): today's bookings with arrival state, one search box for name / phone / check-in code, and Scan QR. One tap marks Arrived.
  6. Every confirmation message carries a QR (image header) and the 6-character check-in code. The QR holds only the code.
  7. Booking mode off: no Bookings entry in the sidebar; the page shows "Bookings are off".
